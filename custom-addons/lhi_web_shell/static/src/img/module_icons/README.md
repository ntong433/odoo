# LHI module icons

These SVGs are vendored from [Bootstrap Icons 1.11.3](https://github.com/twbs/icons/tree/v1.11.3),
licensed under the MIT License. The unmodified upstream license is stored in `LICENSE`.

The filenames are semantic LHI application keys rather than translated labels or
database identifiers. Dashboard navigation resolves the target independently via
an Odoo menu XML ID; a missing image therefore cannot break navigation.
